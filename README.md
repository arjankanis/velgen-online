# Kampen City

Low-poly GTA 1-inspired browsergame set in a stylized version of Kampen, Netherlands.

## Development

```bash
npm install
npm run dev
```

## Production / Cloudflare Pages

Build command: `npm run build`  
Output directory: `dist`

Controls: WASD / arrow keys to drive or walk, E to enter/exit vehicle. On mobile, use the on-screen controls.

This is an early prototype; the city map is stylized, not geographically exact.
